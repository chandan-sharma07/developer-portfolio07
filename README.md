## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/chandan-sharma07/developer-portfolio07.git
```

### Navigate to project

```bash
cd developer-portfolio07
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
